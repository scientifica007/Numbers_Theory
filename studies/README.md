## حدود الاعتماد

- الدراسات 06–09 و11–13 تدوين منظم للمضمون الرياضي المتاح في المحادثة: التعريفات والنتائج والبراهين والحدود، لا نسخ حرفية كاملة. أضيفت توضيحات صورية محدودة عند التدوين، مثل الفصل بين الكتل المساعدة والحالات المولدة وشروط الاستدلال الكلاسيكي.
- الإصدار 0.2 والدراسة العاشرة خضعا لتحكيم ثان مستقل واحد؛ القبول الرياضي مشروط. ليس هذا تحكيمًا شاملًا للنصوص الأصلية لكل الدراسات.
- نتائج T27–T47 غير مدرجة في إصدار رسمي جديد، ولم تخضع للتحقق الآلي أو لتحكيم مستقل.
- أرقام T01–T47 تسلسل للنتائج والتعريفات والملاحظات؛ ليست عددًا لمبرهنات جديدة مستقلة أو ادعاءات بالأسبقية.
- النموذج المجموعاتي والمخزون والاستدلال البنيوي ما زالت فرضيات أو أدوات خلفية معلنة. تقليل الأدوات المباشرة لا يثبت تقليل القوة التأسيسية الإجمالية.
